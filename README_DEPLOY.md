# تعليمات الرفع على InfinityFree

لرفع الموقع بنجاح على InfinityFree، اتبع الخطوات التالية:

1. **بناء المشروع**: قم بتشغيل الأمر `npm run build` في جهازك المحلي.
2. **المجلد الناتج**: سيتم إنشاء مجلد باسم `dist`.
3. **الرفع**: قم برفع **محتويات** مجلد `dist` (وليس المجلد نفسه) إلى مجلد `htdocs` في حساب InfinityFree الخاص بك عبر FTP أو مدير الملفات.
4. **التوجيه**: لقد قمت بإضافة ملف `.htaccess` تلقائياً لضمان عمل الروابط (Routing) بشكل صحيح عند إعادة تحميل الصفحة.
5. **المسار**: تم ضبط المسار ليكون نسبياً (`base: './'`) لضمان عمل الموقع سواء كان في المجلد الرئيسي أو مجلد فرعي.

**ملاحظة**: تأكد من أن ملف `.htaccess` قد تم رفعه مع الملفات الأخرى، فهو المسؤول عن توجيه الطلبات إلى `index.html`.
